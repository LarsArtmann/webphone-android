# Domain Language

> The ubiquitous language of this project. Every term used in code,
> conversations, and docs should be defined here unambiguously.

## Core terms

| Term                     | Definition                                                                                                                                                                                                       | Where used in code                                                              |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| the island               | The webphone web application: the tab surfaces (Messages, Fax, Voicemail, History, Contacts, Settings)                                                                                                           | `shell/MainActivity.kt`, `shell/SessionApi.kt` KDocs                            |
| the stack                | The webphone server platform the island and this shell both talk to                                                                                                                                              | README, `shell/SessionApi.kt`                                                   |
| stack origin             | The stack's base URL; the one configuration constant (`App.origin`)                                                                                                                                              | `App.DEFAULT_ORIGIN` / `App.origin`, `shell/SessionApi.kt`                      |
| the shell                | This app: the Android native-call shell wrapping the island's pages in a WebView                                                                                                                                 | README, `shell/` package                                                        |
| call contract            | The SIP signaling + WebRTC media ownership the platform decision moved from the browser into Kotlin                                                                                                              | README, `shell/MainActivity.kt` KDoc                                            |
| ring fact                | The push payload `{event, from, call_id}` both transports carry; becomes a system call in the router                                                                                                             | `push/RingRouter.kt`, `push/FcmReceiver.kt`, `push/NtfySubscriptionService.kt`  |
| lane                     | A push transport: the FCM lane (GMS devices) or the ntfy lane (de-Googled)                                                                                                                                       | README, `push/*` KDocs                                                          |
| device train             | A real-device validation round against live infrastructure (the first one retires the honesty contract)                                                                                                          | README, `call/CallActivity.kt` KDoc                                             |
| honesty contract         | The README section listing what is implemented-but-untested; markers, not marketing                                                                                                                              | README "Status: v0.1 scaffold"                                                  |
| session seam             | The cookie → SIP-credentials exchange: WebView login mints the cookie, `resumeSession` trades it for registration facts                                                                                          | `shell/SessionApi.kt` KDoc                                                      |
| FGS                      | Typed Android foreground service: `microphone\|phoneCall` for a live call, `dataSync` for the ntfy subscription                                                                                                  | `AndroidManifest.xml`, `call/CallService.kt`, `push/NtfySubscriptionService.kt` |
| self-managed connection  | A Telecom `Connection` with `PROPERTY_SELF_MANAGED`: the app owns its call UI, the OS gets call-state integration (BT, watches, DND)                                                                             | `call/CallConnectionService.kt`                                                 |
| FSI (full-screen intent) | The incoming-call notification that takes over the lockscreen; `USE_FULL_SCREEN_INTENT` permission                                                                                                               | `push/RingRouter.kt`, `AndroidManifest.xml`                                     |
| hostToken                | The generated `<uuid12>.invalid` token in Via/Contact headers — the WSS NAT convention, deliberately not a real hostname                                                                                         | `sip/SipEngine.hostToken`                                                       |
| sipfrag                  | The `message/sipfrag` body of a NOTIFY carrying the REFER transfer verdict (`SIP/2.0 200 OK` = success)                                                                                                          | `sip/SipEngine.refer`                                                           |
| equals form              | The `Signal=5` encoding of `application/dtmf-relay`; never the colon form (FreeSWITCH 200-OKs and drops it)                                                                                                      | `sip/SipEngine.dtmf`                                                            |
| watchdog                 | The bounded liveness discipline: registration refreshed at expires/2, dead socket rebuilt after backoff — UI state follows the engine, never the socket                                                          | `sip/SipEngine` (refresh/watchdog scheduling)                                   |
| de-Googled               | Devices without Play services; the ntfy lane exists for them with zero Google dependencies                                                                                                                       | README, `push/NtfySubscriptionService.kt`                                       |
| sideload lane            | Distribution outside Play; keeps the default full-screen-intent grant that Play would re-audit                                                                                                                   | README "Distribution", `push/RingRouter.kt`                                     |
| upsert by device id      | The push-registry row model: token rotation replaces the row keyed by the stable per-install `device_id`                                                                                                         | `shell/SessionApi` (push-device upsert), `shell/DeviceIdentity.kt`              |
| CallLayer                | The idempotent process-level wire: session resume → SIP engine → push lanes → session watcher; callable from any wake path, never stacked                                                                        | `shell/CallLayer.kt`                                                            |
| stand-down               | The `ring_end` retreat: cancel the ring notification, tear the Telecom connection, refuse the pending invite — everywhere at once, no half-rings                                                                 | `push/RingEvent.kt`, `call/CallEngine.cancelRinging`                            |
| bootstrap race           | The ring push wakes the process BEFORE the SIP INVITE lands; `CallLayer.ensureWired` must bring the leg up in time — whether the server re-invites long enough is the open question the first live train answers | `shell/CallLayer.kt`, `push/RingEvent.ring` KDoc                                |
| registration state       | The OFF/CONNECTING/REGISTERED fact the badge and the dialer's Call gate render — the user sees the PBX, instead of flying blind                                                                                  | `call/CallEngine.kt`, `shell/MainActivity.kt`, `call/DialpadActivity.kt`        |
| addCall session          | The modern Telecom VoIP path (API 34+): `TelecomManager.addCall` returns a `CallControl` the app mirrors engine state onto; the classic self-managed OUTGOING entry no longer exists in the API 36 stubs         | `call/TelecomOutgoing.kt`                                                       |
| endedBy                  | Who ended the call (LOCAL/REMOTE/FAILED) — the Telecom DisconnectCause's source of truth                                                                                                                         | `call/CallEngine.CallState`, `call/CallConnectionService.kt`                    |
| origin                   | Shorthand for the stack origin; persisted in Settings, first-run prompt when still the placeholder                                                                                                               | `App.kt`, `shell/SettingsActivity.kt`                                           |
| train kit                | The self-serve device loop: `.#emulator` devShell + `scripts/emulator-train.sh` (boot/install/launch/screenshot) — the no-operator smoke                                                                         | `flake.nix`, `scripts/`                                                         |
