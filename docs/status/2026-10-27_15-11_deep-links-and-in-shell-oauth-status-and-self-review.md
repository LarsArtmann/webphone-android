## e) WHAT WE SHOULD IMPROVE

1. **`retry()` does not clear the auth detour** — the ONLY reload path that forgets (`loadOriginIfChanged`, `loadUri`, renderer-rebuild all clear). Consequence: transport failure on an IdP page → user taps Retry → origin root loads with a STALE blessing; a later link to that IdP authority would render in-shell for no legitimate reason. One-line fix + one test line. Found by this self-review; NOT yet applied (this report was commissioned first — applying it is next-step #1).
2. **`onNewIntent` itself is untested** — `routeDeepLink` is pinned, but the override (delegate + `setIntent`) is dead-verified. Protected visibility blocks the direct call; a ShadowActivity-style harness or a visibility bump would close it.
3. **Detour activation robustness** — hook `onPageStarted` (foreign main-frame start ⇒ unjudged by construction) alongside `doUpdateVisitedHistory`; idempotent blessing makes the redundancy free and kills the single-hook assumption risk from (b1).
4. **AGENTS.md status header drift** — still says "25 tests" (stale since two sessions ago; now 88) and predates deep links/OAuth. The header is the first thing a fresh session reads; it must not lie.
5. **Memory gaps this session exposed**: (i) the rg `-r` trap (third strike, still unwritten), (ii) the exact zipalign invocation path, (iii) both belong in project memory/AGENTS; the rg lesson generalizes cross-project (crush-config `references/lessons.md`).
6. **CI remains a ghost guarantee** — triggers are `pull_request`/`workflow_dispatch` and it has NEVER run; all 88 greens are local-machine truth. The new detour/intake tests are exactly the kind of thing CI exists to protect.
7. **Robolectric vs Chromium gap**: this repo has now hit the "shadow doesn't reproduce real WebView glue" wall twice (CookieManager NPE 2026-10-24; today's redirect-callback semantics). Any WebView-callback-derived policy deserves an emulator proof before it's called done — worth writing into the honesty contract language.
